## ✨ About the Project

Engineer's Journey is an interactive portfolio designed around the idea of exploring different stages of an engineer's journey.

Visitors can explore different sections, discover technical skills and projects, view achievements, and connect with me. A quest-based progression system adds an interactive element while keeping important professional information easy to access.

## 🚀 Features

- **Interactive RPG-inspired UI:** Pixel-art-inspired visual design and themed portfolio sections.
- **Quest Journal:** Tracks exploration progress across portfolio sections.
- **XP & Rewards System:** Earn experience points by completing portfolio quests.
- **Project Showcase:** Highlights technical projects, technologies and development work.
- **Responsive Design:** Designed for desktop and mobile screens.
- **Resume Access:** Direct access to my resume PDF.
- **GitHub & LinkedIn Integration:** Quick access to my professional profiles.
- **Session-based Progress:** Quest progress is maintained during the browser session.

## ⚙️ Run Locally

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/AryaMourya/engineers-journey.git
```

2. Navigate to the project directory:

```bash
cd engineers-journey
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

### Production Build

To create an optimized production build:

```bash
npm run build
```

The generated production files are stored in the `dist` directory.
